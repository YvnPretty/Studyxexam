# Studyxexam

Examen interactivo de 30 preguntas sobre API REST, PHP, Laravel y MongoDB.

- 6 bloques de 5 preguntas.
- Calificación automática sobre 100.
- Revisión de respuestas.
- Sin registro ni almacenamiento de datos personales.

## Publicación

En GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main → / (root) → Save**.

Después de publicar: https://YvnPretty.github.io/Studyxexam/
